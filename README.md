# Blockchain Technology: class site

This repo is one class's site, or the template that class sites are made from.

Generated by `tools/cut_delivery.py` in the course repo. Don't edit the site files here; change the course repo
and cut again.

## Start a class

1. Make a repo for the class from this template ("Use this template" on GitHub).
2. Turn on Pages for it (GitHub: Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
3. Open the class site. It says the class isn't set up yet: follow "set up this class".
4. Commit the settings file the setup page gives you (`assets/kit/class.js`).

After that, this repo's issues are the class's records. They are encrypted: please don't edit or close them.
