Class results

Pulls sealed submissions from the class inbox (or from codes students handed in), decrypts them with the class private key, checks each student's signature, grades them, and totals the class. This page holds no secrets: without the class key it can read nothing. The inbox is the class's database: registrations, submissions and your reset decisions are all records in it. Everything happens in this browser: nothing is uploaded anywhere.
