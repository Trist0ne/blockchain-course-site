Set up this class

Three steps: make a token, paste it here, commit one file. Everything is generated in this browser.

1. This class

Change the repo, or use GitLab or a self-hosted server

2. The inbox token

Students' pages save their work as issues in this class's repo. They do it with a token that can do that and nothing else.

Run this class without an inbox

Leave the token empty and press the button. Students then hand in their work as codes (Copy or Download), and you paste those into the dashboard. Use this when the classroom can't reach the platform at all.
