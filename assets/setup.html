2. The inbox token

Student pages file their submissions as issues in this class's repo, using a token that can do nothing else. Create one that is limited to this repo, with Issues read and write, and set it to expire when the class ends.

  • GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens. Repository access: only this repo. Permissions: Issues, read and write.
  • GitLab: the project's Settings → Access tokens. Role Reporter, scope api.

Leave the token empty to run without an inbox. Students then hand in codes by Copy or Download.
